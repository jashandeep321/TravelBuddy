# 🌍 Travel Buddy: A Travel Guide App

🔗 [Visit the Live Site](https://travelbuddy-7edk.onrender.com/)

## 📌 Objective
Travel Buddy is an AI-powered travel itinerary platform designed to revolutionize how users plan and manage their trips. It provides a personalized, end-to-end travel planning experience, simplifying the entire process through intelligent recommendations based on user preferences, past travel history, and real-time data.

---

## 🧰 Tech Stack
- **Frontend:** React.js, Redux, React Router
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (MongoDB Atlas)
- **AI Integration:** Gemini Google AI API
- **Cloud Services:** AWS, Azure
- **APIs:** Google Maps API, Various Travel APIs
- **Dev Tools:** MongoDB Compass, Docker, Kubernetes (for deployment), Postman

---

## ✨ Key Features
- ✈️ AI-generated personalized travel itineraries
- 🧭 Smart recommendations for destinations, activities, hotels
- 📊 Budget planner with min-max expense estimations
- 🔁 Real-time feedback loop to refine itineraries
- 🔐 JWT-based user authentication
- 📱 Responsive frontend with seamless navigation
- 🌐 RESTful API integration between frontend and backend

## ⚙️ Installation & Running Locally

### Prerequisites
- Node.js
- MongoDB Atlas account
- npm / yarn

### Steps
1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/travel-buddy.git
   cd travel-buddy

2. **Set up environment variables:**
   Create a .env file and configure MongoDB URI, JWT secret, and API keys.
   
3. **Install dependencies:**
   cd backend
   npm install
   cd ../frontend
   npm install

4.**Start the app:**
  Backend:  node index.js
  frontend: npm start
